# Documentacion ORKA IoT

Este directorio contiene la documentacion operativa del stack.

## Indice

- `01-arquitectura.md`: arquitectura, red Docker, persistencia y flujo de datos.
- `02-instalacion-orange-pi.md`: instalacion en Orange Pi (objetivo principal).
- `03-instalacion-windows.md`: modo de prueba en Windows.
- `04-operacion.md`: operacion diaria, logs, pruebas y actualizacion.
- `05-thingsboard-nodered.md`: integracion Zigbee2MQTT -> Node-RED -> ThingsBoard.
- `06-cicd-orange-pi-runner.md`: runner self-hosted y deploy por GitHub Actions.
- `07-backup-restore.md`: politicas de backup y pasos de restauracion.
- `08-troubleshooting.md`: problemas comunes y solucion.
- `09-instalacion-azure-vm.md`: instalacion en Azure VM (Ubuntu por SSH).
- `10-arquitectura-cloud-edge.md`: diseno recomendado cloud central + edges.
- `11-instalacion-edge.md`: instalacion de stack edge en Orange Pi/Raspberry Pi.
